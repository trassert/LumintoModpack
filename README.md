Рекомендуемая сборка для игры на нашем сервере.

## Установка

### На лаунчерах без поддержки Modrinth

- Перейдите в [**Modrinth**](https://github.com/trassert/LumintoModpack/releases)
- Скачайте `Source code (zip)`
<img width="386" height="229" alt="изображение" src="https://github.com/user-attachments/assets/31f94163-4e3d-4bb4-9d8a-da2ba641cc1f" />

- В нём находятся папки `mods`, `resourcepacks`, `configureddefaults` - расположите их в корне игры

### На Prism Launcher

- Просто напишите `Luminto` в поиске сборок.
